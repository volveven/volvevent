2. Überblick

Diese Website ist eine rein statische Informationsseite. Wir legen Wert darauf, so wenige Daten wie möglich zu verarbeiten:

  • Es werden keine Cookies gesetzt und kein Local Storage verwendet.
  • Es findet kein Tracking statt; es werden keine Analyse- oder Statistik-Tools eingesetzt.
  • Es werden keine externen Schriftarten, Skripte oder Content-Delivery-Networks (CDNs) eingebunden. Schriftarten und alle weiteren Dateien werden direkt von dieser Website geladen.
  • Es gibt keine Kontaktformulare und keine Benutzerkonten.

Personenbezogene Daten werden daher nur in den nachfolgend beschriebenen Fällen verarbeitet: beim technisch notwendigen Abruf der Website durch den Hosting-Anbieter und wenn Sie uns per E-Mail kontaktieren.

3. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Anbieter ist die GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA („GitHub“).

Beim Aufruf der Website verarbeitet GitHub automatisch Daten, die Ihr Browser übermittelt, und speichert diese in Server-Log-Dateien. Dazu gehören insbesondere Ihre IP-Adresse, Datum und Uhrzeit des Abrufs, die aufgerufene Seite, Browsertyp und -version, Betriebssystem sowie die Referrer-URL. Diese Daten sind technisch erforderlich, um die Website auszuliefern sowie ihre Stabilität und Sicherheit zu gewährleisten.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Unser berechtigtes Interesse liegt in einer sicheren, zuverlässigen und effizienten Bereitstellung der Website. Auf Art und Dauer der Speicherung durch GitHub haben wir keinen Einfluss.

Dabei können Daten in die USA übermittelt werden. Die Übermittlung stützt sich auf den Angemessenheitsbeschluss der Europäischen Kommission zum EU-US Data Privacy Framework (Art. 45 DSGVO), soweit GitHub unter diesem Rahmen zertifiziert ist. Weitere Informationen finden Sie in der Datenschutzerklärung von GitHub: GitHub General Privacy Statement.
